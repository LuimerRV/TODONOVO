# TODONOVO · Maqueta del sitio

Maqueta navegable del ecommerce TODONOVO (diseño, no conectada a Shopify).

## Páginas
- `index.html` · Inicio
- `tienda.html` · Tienda: catálogo, resultados de búsqueda (`tienda.html#q-organizador`) y ficha de producto (`tienda.html#p-kitviaje`)
- `quienes-somos.html` · Quiénes somos
- `preguntas-frecuentes.html` · Preguntas frecuentes
- `contacto.html` · Contacto

## Ver en local
Abre `index.html` en el navegador. Para que todo funcione igual que publicado, conviene servir la carpeta, por ejemplo:

```
npx serve .
```

## GitHub Pages
Sube el contenido de esta carpeta a la raíz del repositorio y activa Pages en Settings > Pages (rama `main`, carpeta `/ (root)`).

## Notas
- Productos, precios, stock, descripciones y especificaciones son de ejemplo.
- Los formularios, el carrito y la búsqueda funcionan solo en la maqueta (no envían datos).
- Tipografías: Big Shoulders Display, Outfit e Inter, desde Google Fonts.
